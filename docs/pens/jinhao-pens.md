# Jinhao Pens

The first Jinhao pen is Baoer 801 Silver Steel, which is also known as Jinhao 801. Baoer is a sub brand of Jinhao. so they same the same look and feel the similar.  it’s every day pen. before buying Wing Sung 3010, I used it everyday. in general it’s smooth no skipping. it may hard start if don’t use for long time

Jinhao 65 Black with extra fine nib is the second one. the reason to buy it as I want to have an EF nib, which is Lamy compatible. it’s Kind of okay but I prefer to use Baoer 801 or Wing Sung 3010.

Jinhao X159 Red with #8 nib. it’s a clown or inspired by Mountblanc 149. I want to have a bigger nib size so I grabbed one. it’s like other hard start if it’s sitting too Long. as the pen size is large, it’s just use on the desktop. I don’t use it everyday. it’s good for signatures or cilligraphy

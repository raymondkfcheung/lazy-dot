# Pilot Hi-Tecpoint V5

The Pilot Hi-Tecpoint V5 is a great pen for daily use, and I like that it uses a cartridge system. I can refill it with different colours, which is convenient. The original pack comes with blue ink and three spare cartridges.

The writing experience is good, and I mainly use it for taking notes and carry it in my bag. Since it’s durable and inexpensive, I don’t have to worry too much about damaging it.

Originally, I wanted to buy a Lamy rollerball, but some reviewers suggested trying the Pilot one, so I gave it a try. So far, it’s been perfect for me.

I also tried filling it with Parker Quink Black, and it works well.
